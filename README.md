# 🚀 Reto 100 Proyectos en Python

¡Bienvenido a mi repositorio del **Reto de 100 Proyectos en Python**! 🐍
Este espacio documenta mi viaje de aprendizaje continuo, desarrollando proyectos desde conceptos básicos hasta arquitectura backend y machine learning.

## 🎯 Objetivo
Completar 100 proyectos prácticos en Python para consolidar mis conocimientos, mejorar mi lógica de programación y crear un portafolio profesional sólido.

## 🗂️ Estructura del Repositorio
El proyecto está organizado jerárquicamente por niveles de dificultad para mantener el orden y mostrar mi progresión:

* 🟢 **`01_Principiante/`** - Scripts, lógica básica, y fundamentos de Python.
* 🟡 **`02_Intermedio/`** - Estructuras de datos, POO, manejo de archivos y APIs simples.
* 🟠 **`03_Avanzado/`** - Desarrollo Backend (FastAPI, SQLAlchemy), bases de datos y ML básico.
* 🔴 **`04_Experto/`** - Arquitecturas complejas, despliegue (Docker), y Machine Learning predictivo.
